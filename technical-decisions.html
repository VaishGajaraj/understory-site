Decisions, in order

Lock these before publishing a number

01

Use one canonical raster CRS

Implemented

Decision: keep analysis in each frame’s native projected CRS. Calculate areas there, then reproject detection geometry to EPSG:4326 only for GeoJSON delivery.

Wired: stack.py carries CRS explicitly; events.py transforms exports; masks.py reprojects auxiliary inputs onto the native grid.

02

Select the 20 m coherence layer explicitly

Implemented

Decision: use the delivered 20 m GUNW coherence magnitude for the two-hectare question. Never accept whichever HDF5 dataset the file walker happens to encounter first.

Wired: extraction records frequency, polarization, interferogram group, resolution, source path, and granule provenance.

03

Freeze the benchmark’s product identity

Before data

Decision: one PROVISIONAL tier, CRID, track, frame, direction, polarization, resolution, and date window. Do not mix BETA and PROVISIONAL observations.

Wire into: benchmark YAML plus a generated manifest of granule IDs, checksums, configuration hash, code commit, and label version.

04

Measure against a defensible holdout

Before tuning

Decision: split labels by geography or time before threshold tuning. Add verified negatives and a review state for detections outside incomplete event catalogs.

Wire into: label schema gains verification method, source ID, uncertainty, reviewer, and source version; scoring reports known, rejected, and unreviewed detections separately.

05

Put every threshold in the benchmark config

Implemented

Decision: baseline history, anomaly sigma, persistence, cluster size, and geometry threshold are part of the frozen experiment—not hidden defaults.

Wired: nested configuration now lives in every benchmark YAML and is copied verbatim into generated reports.

06

Separate anomaly severity from probability

After labels

Decision: call the current score anomaly severity. Publish calibrated confirmation probability only after enough independently reviewed detections exist.

Wire into: detector output gains severity; calibration becomes a fitted, versioned layer evaluated on held-out labels.

07

Stay small operationally

Hold

Decision: one AWS us-west-2 machine, temporary Earthdata credentials, range reads, chunked Zarr, and GeoJSON delivery. No GPU, PostGIS, Kubernetes, or custom viewer yet.

Wire into: improve ingestion and provenance first. Add infrastructure only when a named partner’s workflow requires it.

Expansion discipline

What shares the pipeline—and what does not

Same coherence foundation

Illegal mining, timberland monitoring, EUDR evidence, carbon MRV, and partner watch areas can reuse the core pipeline after the benchmark works.

Separate phase-processing projects

Subsidence, tailings dams, and permafrost use interferometric phase and atmospheric correction. Keep them out of this repository until the core question is answered.
