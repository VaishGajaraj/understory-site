01 / The hidden change

A forest can look intact from above while changing underneath

Selective logging leaves skid trails and access roads only metres wide beneath an otherwise closed canopy. Clouds obscure optical satellites. Leaves obscure the ground. The damage can remain invisible during the window when an early warning matters most.

NISAR sends a long-wavelength radar pulse through the canopy. Understory compares the returning signal from one 12-day pass to the next, looking for places where the ground stops matching itself—and where that change persists.

The experiment asks one falsifiable question: can this signal detect documented degradation events at useful precision, at two hectares or smaller, and at least three weeks before optical alerts in cloudy-season tropics?

03 / Kill criteria

The conditions under which this project declares itself dead

These were written before the code was, and they live in the codebase as executable checks rather than as prose. Every benchmark run emits its own verdict — pass, fail, or insufficient data — and a run on synthetic data is marked as scaffolding so it can never be mistaken for a claim.

If the numbers land short, the failure analysis gets published anyway. A benchmark that can only report good news is not a benchmark.

Stated before building
Criterion Threshold Why this number Status
Event precision ≥ 70% Against external ground truth, at operationally useful recall. A partner acting on a false alarm loses a field trip. Not evaluated
Minimum detectable size ≤ 2 ha Most tropical disturbance events are small. A detector blind below 2 ha misses the majority by count. Not evaluated
Lead over optical alerts ≥ 21 days Median, in cloudy-season tropics, against the earliest operational alert — not against a single system. Not evaluated
04 / What exists

The experiment is executable. The evidence is not in.

Ingest

Real NISAR discovery and extraction

Discover GUNW pairs by calibration tier, download a local cached granule, locate its coherence layer, and preserve track, frame, time, and projection metadata.

Detection

Legible statistics before machine learning

A rolling robust baseline per pixel, then persistence, clustering and geometry filters. Machine learning enters only if the benchmark shows it beats the filters.

Context

Known confounders enter explicitly

Forest cover constrains the search area. Terrain can be masked. ERA5 rain and wind can be joined to each pass so natural decorrelation is visible rather than hand-waved.

Ground truth

The schema is ready; the real labels are not

Versioned event collections exist for Pará, eastern woodland, and mining. They are intentionally empty until externally documented events are transcribed and reviewed.

Scoring

Reports are generated, never written

Precision, recall, detection latency, lead over optical, a minimum-size curve, and a calibration table. Published tables come from these files or they do not exist.

Honesty

Confidence has to be earned

Of alerts emitted at a score near 0.8, about 80% should confirm. An overconfident score is treated as a defect of the same severity as a missed detection.

06 / Reproduce it

Everything reproduces from one command

The toy benchmark needs no credentials and no network. It generates a synthetic scene containing one persistent road and one transient rain blob, runs the detector, and asserts that it finds the first and ignores the second. 

# synthetic end-to-end, no credentials needed
make toy-bench

# against the real archive (needs NASA Earthdata credentials)
uv run python scripts/probe_archive.py benchmarks/amazon-para/aoi.yaml

Every benchmark run also writes a QGIS-loadable alerts layer next to its report — the delivery format field partners already use.

07 / Boundaries

Civilian, terrain not people, conservative by default

This instrument reads ground disturbance, not activity. A 12-day repeat cycle makes it an infrastructure-and-pattern instrument by physics rather than by policy. Sensitive geographies are handled under a published governance standard, and defense applications are deliberately out of scope for this repository.

The code is Apache-2.0 and the label library is CC-BY 4.0, governed and versioned separately from the code, because open data outlives pipelines.
